Get started

Choose a folder. Install. Play.

Download and extract the package for your system, open ArenaHub, and sign in to a Steam account that owns Quake III Arena. Team Arena is available when your account owns the expansion. No Python installation needed.

ArenaHub is in the AUR ↗ as arenahub-bin, with its desktop entry and icon.

yay -S arenahub-bin
# or: paru -S arenahub-bin

With Python

ArenaHub is also on PyPI ↗. It runs on Python 3.13, which uv downloads when your system has another version.

uv tool install arenahub
